Loophole for Iterable

One browser extension that replaces a folder of Iterable userscripts — campaign checks, bulk data, template tools and more, all in one install.

Firefox Chrome

Free, open source, community-built. Not affiliated with Iterable.

Why it exists

Iterable is great, but day-to-day work turns up gaps: a check that should be automatic, a step that takes five clicks instead of one. I filled those gaps with userscripts, one at a time. They worked, but each had to be installed, updated and learned separately, and no two looked or behaved alike.

Loophole brings them into one extension. You install and update it once, the tools share one look and one settings page, and adding a new tool is simple, so there are more of them, sooner.

The bigger goal is to make this kind of specialised tooling easy for anyone on an Iterable team, not just the people comfortable with userscripts. Got an idea for something Iterable could do better? I'd love to hear it.

One install, not two dozen

Every tool ships together, versioned together, and updates together. No more chasing down which script is out of date.

Settings and an API key vault

Your project keys live in the extension's own storage, scoped per project, never pasted into a script header again.

Imports your Tampermonkey settings

Export your Tampermonkey storage and Loophole reads it straight in — API keys, tags, UTM libraries and more, carried over automatically.

What's included

Campaigns

  • Campaign checks — seed list, suppression list and subject checks on the campaign page.
  • Approval view — the email details next to the start of the actual email, so one screenshot covers sign-off, with copy card, copy text and copy screenshot.
  • Email HTML check — 20 rules for accessibility, deliverability and rendering.
  • Workflow link parameters — fills Google Analytics and link parameters in journey and template panels.

Templates

  • Live preview editor — live preview beside the code editor, with test data per template and profile-loaded test data.
  • Link parameters — pick UTM values from your own library in the drag-and-drop editor.
  • Delete confirm + undo — optional auto-confirm on delete, plus undo and redo in the drag-and-drop editor.
  • Image library — browse folders, upload, create folders and copy image paths from the template editor.
  • Snippet viewer — search, preview and copy snippets from anywhere.
  • Quick search tags — one-click saved searches above the template list.
  • Locale banner — a clear badge for the locale you're editing.
  • Creative library previews — bigger thumbnails, hover previews and click-to-copy URLs.

Users

  • User lookup — find a user by email or userId from the top bar, straight to their profile.
  • Profile editor — edit profile fields in place, with type checks.
  • Delete user — a two-step delete that shows the exact API call and checks the key belongs to this project.
  • Dynamic list membership — which dynamic lists a user is in.
  • Copy event data — copy a custom event's dataFields as JSON.

Data

  • Bulk data — push users, list subscriptions and catalog items from CSV, and export catalogs. Rate-limited, retried and resumable.
  • Field value explorer — every value of a user field, past the 1,200-value limit.
  • Export field picker — select all, filtered or inverted fields in Export to CSV.

Navigation

  • Quicklinks — your own shortcuts in the top bar.
  • Fill username on login — off by default; fills your username on the sign-in page. Never touches passwords.

Privacy & safety

Keys stay in your browser

Your API keys and settings are stored only in your browser profile. Nothing is synced to a third-party server.

Nothing sent anywhere but Iterable

Loophole talks to your Iterable project and nothing else. There's no analytics call, no telemetry, no third-party endpoint.

Every write needs your click

Anything that writes to Iterable — deletes, profile edits, bulk pushes, uploads — only happens when you click it, and shows what it will do first.

Install

  1. Download the build for your browser from the latest release.
  2. Firefox: drag the .xpi into a Firefox window, or use about:addons → gear icon → Install Add-on From File…
  3. Chrome / Edge: unzip the download, open chrome://extensions, turn on Developer mode, and click Load unpacked.
  4. Coming from Tampermonkey? Export your script storage as a zip, then use Settings → Import from Tampermonkey inside Loophole.

Full step-by-step instructions, including screenshots, are in docs/SETUP.md on GitHub.
